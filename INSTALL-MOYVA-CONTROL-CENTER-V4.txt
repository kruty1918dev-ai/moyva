Moyva Control Center V4 — multi-monitor visual training preview

1. Stop any currently running training.
2. Close Moyva Control Center.
3. Extract this archive over the Moyva project root.
4. On Linux/X11, install the recommended window helpers if they are not already present:

   sudo apt install -y wmctrl xdotool

5. Apply the idempotent launcher + training-player settings patch:

   python3 INSTALL-MOYVA-CONTROL-CENTER-V4.py

6. Rebuild the dedicated training player once so the resizable/background window settings take effect:

   ./moyva build training --rebuild

7. Run the CLI tests and open Control Center:

   ./moyva test quick
   ./moyva

Then use Training -> Start & watch.
The preview should be moved to the monitor not containing Control Center, maximized there, while remaining a normal resizable/minimizable OS window.
