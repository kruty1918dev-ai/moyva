# Official Unity references

The Pass70 installer and bridge were designed against Unity's official 2026 documentation for the experimental Unity CLI and Pipeline package.

- Unity CLI usage:
  https://docs.unity.com/en-us/unity-cli/use-unity-cli

- Unity CLI reference:
  https://docs.unity.com/en-us/unity-cli/unity-cli-reference

- Unity Pipeline package:
  https://docs.unity.com/en-us/unity-production-pipeline/local-tools-cli/unity-pipeline-package

- Unity announcement / examples for Pipeline, `CliCommand`, `eval`, and `eval_file`:
  https://unity.com/blog/meet-the-unity-cli

The installed CLI's `--help` output is authoritative if experimental syntax changes.
